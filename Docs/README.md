
# RoadSenseAI – Project Documentation

This folder contains the main documentation materials for the RoadSenseAI capstone project, including the project book, poster, presentation, and demo video.

## Demo Video

Watch the project demo video here:
[RoadSenseAI – Collaborative Pothole Detection and Mapping](https://www.youtube.com/watch?v=GtwI6-8NaIo)

The demo video presents the main RoadSenseAI workflow: citizen reporting, driving video and GPS upload, AI-based pothole detection, geospatial mapping, admin review, team management, team leader assignment, and repair progress tracking.
